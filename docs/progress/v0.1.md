# diagram-zoom — v0.1.0 tracker

> Execution state + provenance. Design rationale lives in `AGENTS.md` (invariants) and the
> README (user surface). Last updated: 2026-10-10.

## Goal

A public, MIT, installable Quarto extension: `quarto add Lightbridge-KS/quarto-diagram-zoom`, then
`filters: [diagram-zoom]`. Every Mermaid and Graphviz diagram in HTML output gets an Enlarge button
that opens a modal viewer with zoom and pan (wheel, pinch, drag, keys). Shipped as a v0.1.0 draft
GitHub Release. The core JS is host-agnostic so other renderers can vendor the same file.

**Scope decisions (settled):** vector diagrams only (raster images stay with Quarto's `lightbox`) ·
wheel zooms, map-style · v0.1.0 targets HTML documents, books, websites — not Reveal.js · the core
JS is the single source of truth for every host that embeds this viewer · zero configuration in
v0.1.0 (only the `.no-zoom` class).

## Deferred

- Reveal.js support (keyboard conflicts with Reveal shortcuts; slide scaling).
- Configuration knobs (`max-zoom`, a scroll-pans wheel mode, custom selectors).
- Raster images (`<img>` diagrams, `mermaid-format: png`) — Quarto `lightbox` covers them.
- Momentum (inertial) panning on touch.
- Button placement on the SVG's own corner for narrow centred diagrams (`fig-align`).

## Confirmed contracts

- **Quarto Mermaid pipeline** (`formats/html/mermaid/mermaid-init.js`, 1.9.38): renders on
  `window.load` into a transient `<pre class="mermaid-js">`, re-parents the `<svg>`, and runs
  `postProcess` over all `svg.mermaid-js` only after the last diagram renders. Attach Mermaid SVGs
  only once no `pre.mermaid-js` remains; never wrap the SVG (postProcess walks parents).
- **Format guard:** `quarto.doc.is_format("html:js")` is true for revealjs, dashboard, and email;
  the filter adds its dependency only when `html:js and not quarto.format.is_html_slide_output()`.
- **Dependency placement:** core JS + CSS in `<head>`; glue with `afterBody = true` (head scripts
  run before `<body>` exists; `embed-resources` inlines scripts so `defer` does nothing).
- **Cross-ref hover previews** clone figures into `.tippy-box`; the button is skipped and hidden there.
- **Install paths:** `quarto add` from GitHub installs `_extensions/Lightbridge-KS/diagram-zoom`, from a
  local dir `_extensions/diagram-zoom`; `quarto add owner/repo` takes `main`'s archive, `@vX.Y.Z`
  takes the tag — `main` must stay releasable.
- **Mermaid can give up.** A diagram Mermaid cannot lay out (typically hidden in an inactive tab
  or collapsed callout at load) makes Quarto's render loop throw: later `<pre class="mermaid-js">`
  stay and `postProcess` never runs. The glue treats the resulting `unhandledrejection` as
  "settled" and re-scans (`observe().scan()`), so every rendered diagram still gets a button.
- **Never attach to the viewer's own UI.** The Enlarge icon is an `<svg>`; with a match-all host
  it would get its own button, endlessly. `eligible()` skips `aria-hidden="true"` SVGs and
  anything inside `.dz-open` / `.dz-dialog`.
- **Fixture rendering needs a launchable Chrome** (`mermaid-format: svg/png`): `render-fixtures`
  points `QUARTO_CHROMIUM` at Playwright's Chromium; a restrictive local sandbox blocks the
  launch (opaque `AssertionError`), CI relaxes Ubuntu's userns restriction.
- **Quarto 1.9.38 cannot render Graphviz to DOCX** here (`AssertionError`, with or without this
  filter), so the DOCX fixture is text-only — it proves the filter is a no-op, nothing more.
- **Quarto ≤ 1.7: `quarto.format.is_html_slide_output()` is true for every HTML output**
  (aliased to `isHtmlOutput`; fixed in 1.8, quarto-dev/quarto-cli#13334). The guard names slide
  formats with `quarto.doc.is_format` instead.
- **iOS tap activation:** WebKit withholds `click` when the tap's hover changes visible content
  (our old hover-reveal; Quarto's `.quarto-figure:hover > .anchorjs-link`). Hover-reveal is limited
  to `(hover: hover) and (pointer: fine)`; touch/pen open on `pointerup` and swallow only a click
  arriving < 700 ms later (iOS delays ~350 ms). Never disarm on a later event — that ate a Close tap.
- **iOS dialog scrolling:** one-finger drags inside the viewer become native scrolling
  (`pointercancel` despite `touch-action: none`); pinches stay pointer events.
- **Version SSOT:** `_extensions/diagram-zoom/_extension.yml` `version`; the Lua dependency version
  and the JS banner must match (`scripts/check-version.mjs`); release tags must equal it.
